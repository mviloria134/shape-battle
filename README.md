A very simple turn-based battler similar to Pokemon.  

So far, the player can only attack the enemy then go back to the main menu.  

Core Mechanics to finish:  
- implement the enemy's turn
- Mons faint at 0 HP
- win/lose the battle

Future Plans:  
- switch mons
- status-inflicting skills
- item usage
- run from battle

Battle background asset from [Chris Courses's tutorial](https://www.youtube.com/watch?v=yP5DKzriqXA) on making a Pokemon JavaScript game. (The actual game's implementation is my own, however).  

All other art assets were made by me.
